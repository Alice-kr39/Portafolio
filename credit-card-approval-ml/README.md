
# Credit Card Approval Predictor 

## Descripción
Modelo de Machine Learning para predecir automáticamente 
si una solicitud de tarjeta de crédito será aprobada o rechazada,
similar a los sistemas usados por bancos comerciales reales.

## Dataset
- **Fuente:** UCI Machine Learning Repository
- **Nombre:** Credit Card Approval Dataset
- **Registros:** 690 solicitudes
- **Variables:** 15 atributos + 1 variable objetivo (aprobado/rechazado)
- **Nota:** Los nombres de variables fueron anonimizados 
  para proteger confidencialidad

## Flujo del Proyecto
1. Exploración y análisis de datos (EDA)
2. Limpieza de datos y manejo de valores nulos
3. Preprocesamiento (encoding + escalado)
4. Entrenamiento del modelo (Regresión Logística)
5. Evaluación y optimización (GridSearchCV)

## Tecnologías
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn
- Google Colab

## Resultados
 Accuracy final: 84.06%
 Falsos positivos: 12
 Falsos negativos: 10
